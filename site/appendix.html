CodePipeline CLI Commands

# Pipeline list দেখা
aws codepipeline list-pipelines

# Pipeline-এর details দেখা
aws codepipeline get-pipeline --name MyPipeline

# Pipeline manually trigger করা (Release change)
aws codepipeline start-pipeline-execution --name MyPipeline

# Pipeline execution state দেখা
aws codepipeline get-pipeline-execution \
  --pipeline-name MyPipeline \
  --pipeline-execution-id EXECUTION_ID

# সব execution history দেখা
aws codepipeline list-pipeline-executions --pipeline-name MyPipeline

# Execution stop করা
aws codepipeline stop-pipeline-execution \
  --pipeline-name MyPipeline \
  --pipeline-execution-id EXECUTION_ID \
  --abandon  # অথবা ছাড়া (wait for in-progress actions)

# Manual approval approve করা
aws codepipeline put-approval-result \
  --pipeline-name MyPipeline \
  --stage-name Staging \
  --action-name ManualApproval \
  --result "summary=Approved,status=Approved" \
  --token TOKEN_FROM_APPROVAL_ACTION

# Transition enable/disable
aws codepipeline disable-stage-transition \
  --pipeline-name MyPipeline \
  --stage-name Deploy \
  --transition-type Inbound \
  --reason "Maintenance"

aws codepipeline enable-stage-transition \
  --pipeline-name MyPipeline \
  --stage-name Deploy \
  --transition-type Inbound

# Pipeline delete করা
aws codepipeline delete-pipeline --name MyPipeline

CodeBuild CLI Commands

# Build project list
aws codebuild list-projects

# Build project details
aws codebuild batch-get-projects --names MyAngularBuild

# Build manually start করা
aws codebuild start-build --project-name MyAngularBuild

# চলমান build-এর status দেখা
aws codebuild batch-get-builds --ids BUILD_ID

# সাম্প্রতিক build history
aws codebuild list-builds-for-project --project-name MyAngularBuild

# Build log দেখা (CloudWatch Logs)
aws logs get-log-events \
  --log-group-name /aws/codebuild/MyAngularBuild \
  --log-stream-name BUILD_ID

# Build project delete
aws codebuild delete-project --name MyAngularBuild

CodeDeploy CLI Commands

# Application list
aws deploy list-applications

# Deployment group list
aws deploy list-deployment-groups --application-name MyAngularApp

# Deployment create করা (manual)
aws deploy create-deployment \
  --application-name MyAngularApp \
  --deployment-group-name TaggedEC2Instances \
  --s3-location bucket=my-bucket,key=my-artifact.zip,bundleType=zip

# Deployment status দেখা
aws deploy get-deployment --deployment-id DEPLOYMENT_ID

# Deployment list (application-এর জন্য)
aws deploy list-deployments \
  --application-name MyAngularApp \
  --deployment-group-name MyAutoScalingGroup

# Deployment rollback করা
aws deploy stop-deployment --deployment-id DEPLOYMENT_ID

# EC2 instance-এ CodeDeploy agent status
sudo service codedeploy-agent status
sudo service codedeploy-agent start
sudo service codedeploy-agent stop

# Deployment log (EC2-তে)
cat /opt/codedeploy-agent/deployment-root/deployment-logs/codedeploy-agent-deployments.log

ECR & ECS CLI Commands

Amazon ECR

# ECR login (private registry)
aws ecr get-login-password --region eu-west-1 | \
  docker login --username AWS --password-stdin \
  ACCOUNT_ID.dkr.ecr.eu-west-1.amazonaws.com

# ECR Public Gallery login (us-east-1 required)
aws ecr-public get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin public.ecr.aws

# Repository তৈরি করা
aws ecr create-repository --repository-name my-angular-app

# Repository list
aws ecr describe-repositories

# Image list
aws ecr describe-images --repository-name my-angular-app

# Image tag দিয়ে push করা
docker tag my-app:latest ACCOUNT_ID.dkr.ecr.REGION.amazonaws.com/my-angular-app:latest
docker push ACCOUNT_ID.dkr.ecr.REGION.amazonaws.com/my-angular-app:latest

# Untagged images delete করা
aws ecr batch-delete-image \
  --repository-name my-angular-app \
  --image-ids imageTag=latest

Amazon ECS

# Cluster list
aws ecs list-clusters

# Service list
aws ecs list-services --cluster my-cluster

# Service details
aws ecs describe-services --cluster my-cluster --services my-rolling-service

# Service update (new task definition revision দিয়ে)
aws ecs update-service \
  --cluster my-cluster \
  --service my-rolling-service \
  --task-definition my-angular-task-definition:REVISION

# Running tasks list
aws ecs list-tasks --cluster my-cluster --service-name my-rolling-service

# Task definition list
aws ecs list-task-definitions --family-prefix my-angular-task-definition

# Task definition register (JSON থেকে)
aws ecs register-task-definition --cli-input-json file://task-definition.json

# Force new deployment
aws ecs update-service \
  --cluster my-cluster \
  --service my-rolling-service \
  --force-new-deployment

buildspec.yml Reference

সম্পূর্ণ Structure

version: 0.2

# Environment variables (optional)
env:
  variables:
    MY_VAR: "plaintext-value"
    ECR_REPO_NAME: my-angular-app
  parameter-store:
    DOCKERHUB_TOKEN: /dockerhub/token
    DOCKERHUB_USER: /dockerhub/user
  secrets-manager:
    DB_PASSWORD: myapp/prod:db_password

phases:
  install:               # Runtime ও tools install
    runtime-versions:
      nodejs: 20
    commands:
      - npm install -g @angular/cli@17

  pre_build:             # Dependencies ও login
    commands:
      - npm install
      # ECR login
      - ECR_MAIN_URI=${AWS_ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com
      - aws ecr get-login-password --region ${AWS_REGION} | docker login --username AWS --password-stdin ${ECR_MAIN_URI}

  build:                 # Main build commands
    commands:
      - ng build -c production
    finally:             # Success বা fail — always runs
      - echo "Build finished"

  post_build:            # Push, notifications, etc.
    commands:
      - docker push ${ECR_IMAGE_URI}
      - printf '[{"name":"angular-app","imageUri":"%s"}]' ${ECR_IMAGE_URI} > imagedefinitions.json

# Build artifacts (optional)
artifacts:
  base-directory: dist/my-angular-project    # Angular build output
  files:
    - "**/*"

# Alternatively, for ECS deploy:
# artifacts:
#   files:
#     - imagedefinitions.json

# Test reports (optional)
reports:
  my-test-report:
    files:
      - "**/*.xml"
    base-directory: test-results

appspec.yml Reference (EC2)

সম্পূর্ণ Structure

version: 0.0
os: linux   # অথবা windows

# কোন files কোথায় copy করবে
files:
  - source: dist/my-angular-project   # revision-এ relative path
    destination: /var/www/my-angular-project

# Optional: file permissions
permissions:
  - object: /var/www/my-angular-project
    pattern: "**"
    mode: "0755"
    owner: root
    group: root
    type:
      - file
      - directory

# Deployment lifecycle event hooks
hooks:
  ApplicationStop:
    - location: deploy-scripts/stop-app.sh
      timeout: 300

  BeforeInstall:
    - location: deploy-scripts/before-install.sh
      timeout: 300

  AfterInstall:
    - location: deploy-scripts/after-install.sh
      timeout: 300

  ApplicationStart:
    - location: deploy-scripts/application-start-hook.sh
      timeout: 300
      runas: root    # optional

  ValidateService:
    - location: deploy-scripts/validate.sh
      timeout: 300

application-start-hook.sh উদাহরণ

#!/bin/bash

# Nginx web server restart করুন
sudo service nginx restart

Buildspec artifacts section (CodeDeploy-এর জন্য)

artifacts:
  files:
    - dist/my-angular-project/**/*   # deployable files
    - appspec.yml                     # CodeDeploy spec
    - deploy-scripts/**/*             # hook scripts
  # base-directory সরিয়ে ফেলুন — সব path root থেকে

Lifecycle Events Summary (EC2, without ALB)

ApplicationStop → DownloadBundle → BeforeInstall → Install
→ AfterInstall → ApplicationStart → ValidateService

Lifecycle Events (EC2, with ALB)

BeforeBlockTraffic → BlockTraffic → AfterBlockTraffic
→ ApplicationStop → DownloadBundle → BeforeInstall → Install
→ AfterInstall → ApplicationStart → ValidateService
→ BeforeAllowTraffic → AllowTraffic → AfterAllowTraffic

⚠️ ECS/Lambda-তে appspec file-এর নাম appspec.yaml (yaml extension), EC2-তে appspec.yml (yml)।

Multiple containers

buildspec-এ dynamic generation

post_build:
  commands:
    # Commit ID দিয়ে ECR image URI
    - ECR_IMAGE_URI=${AWS_ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com/my-angular-app:${CODEBUILD_RESOLVED_SOURCE_VERSION:0:8}

শব্দকোষ (Glossary)

AWS CodePipeline

Pipeline
Software change-এর release workflow।
Stage
Pipeline-এ action-এর logical group।
Action
Stage-এর মধ্যে একটি নির্দিষ্ট কাজ (build, test, deploy)।
Action Group
একই stage-এ parallel action-এর set।
Artifact
Action-এর output file, পরবর্তী action-এর input।
Artifact Store
Artifact রাখার S3 bucket, region-ভিত্তিক।
Transition
দুটি stage-এর মধ্যে flow connector, enable/disable করা যায়।
Source Revision
Source location-এ পরিবর্তন — pipeline trigger করে।
Execution ID
প্রতিটি pipeline execution-এর unique ID।
Superseded
Stage-এর বাইরে নতুন execution দ্বারা replaced পুরনো execution।
Variable Namespace
Action output variables-এর prefix, অন্য action-এ reference করতে ব্যবহার।
#{NS.Var}
Action variable reference syntax।

AWS CodeBuild

buildspec.yml
CodeBuild-কে build instruction দেওয়ার YAML file।
Build Phase
install, pre_build, build, post_build।
finally block
Phase succeed বা fail নির্বিশেষে execute হওয়া commands।
Privileged Mode
Docker image build করতে Docker daemon access।
CODEBUILD_RESOLVED_SOURCE_VERSION
40-char Git commit ID — CodePipeline pass করে।

AWS CodeDeploy

CodeDeploy Agent
EC2-তে installed software — deployment poll ও execute করে।
appspec.yml
CodeDeploy deployment specification file।
Deployment Group
Deploy target — tagged EC2 বা ASG।
In-Place Deployment
Existing instance-এ deploy।
Blue/Green Deployment
নতুন instance fleet তৈরি করে deploy, traffic switch।
AllAtOnce / OneAtATime
Deployment configuration — সব একসাথে বা একটি একটি।

Amazon ECS & ECR

Amazon ECR
AWS managed Docker image registry।
ECS Task Definition
Container spec — image, CPU, memory, ports।
ECS Service
Desired tasks count সবসময় running রাখার mechanism।
ECS Cluster
Tasks/services-এর logical group।
Fargate
Serverless ECS infrastructure — AWS managed।
imagedefinitions.json
ECS deploy action-এর contract — container name + image URI।
Deployment Circuit Breaker
ECS automatic failure detection — 10+ task failures।
Min/Max Running Tasks
Rolling deployment-এর task count control percentage।

AWS CloudFormation

CloudFormation Stack
Template থেকে তৈরি AWS resources-এর collection।
CAPABILITY_IAM
Template-এ IAM resource থাকলে required capability।
Change Set
Stack-এ কী পরিবর্তন হবে তার preview।
Parameter Override
Pipeline action-এ template parameter value JSON-এ pass।

সমস্যা সমাধান (Troubleshooting)

AWS CodePipeline

Symptom (লক্ষণ) সম্ভাব্য কারণ সমাধান
Pipeline trigger হচ্ছে না Source bucket-এ versioning off / CloudWatch Events rule নেই / transition disabled S3 versioning enable করুন। Pipeline settings-এ CloudWatch Events rule আছে কিনা চেক করুন। Transition enable করুন।
Pipeline stage fail with "Access Denied" Pipeline service role-এ insufficient permissions IAM Console-এ pipeline-এর service role-এ missing permissions যোগ করুন।
Cross-region deploy action networking error Second region-এ artifact store নেই Second region-এ একটি temp pipeline তৈরি ও execute করুন — artifact store auto-create হবে।
Manual Approval URL invalid Static URL হার্ডকোড, stack recreate-এ DNS change হয়েছে CloudFormation action-এ variable namespace দিন। Approval URL-এ #{NS.OutputKey} reference করুন।
Execution "Superseded" state-এ আটকে আছে Newer execution পুরনোটিকে replace করেছে Normal behavior। History-তে দেখুন। Staging stage আগে ঠিক করুন।

AWS CodeBuild

Symptom সম্ভাব্য কারণ সমাধান
YAML_FILE_ERROR: buildspec not found Source code-এর root-এ buildspec.yml নেই buildspec.yml অবশ্যই root-এ থাকতে হবে। Custom path হলে CodeBuild project-এ specify করুন।
docker: Cannot connect to the Docker daemon Privileged mode disabled CodeBuild project-এ Environment → Privileged checkbox enable করুন।
toomanyrequests: Too Many Requests (Docker Hub) Unauthenticated Docker Hub pull limit reached pre_build-এ Docker Hub login যোগ করুন। অথবা ECR Public Gallery ব্যবহার করুন।
no basic auth credentials (ECR) ECR login command নেই বা IAM permission নেই pre_build-এ aws ecr get-login-password command যোগ করুন। Role-এ ECR permissions দিন।
SecretValueNotFound / ParameterNotFound IAM role-এ Secrets Manager / SSM permission নেই CodeBuild role-এ secretsmanager:GetSecretValue বা ssm:GetParameters policy যোগ করুন।
Runtime version not found Buildspec-এ requested runtime CodeBuild image-এ নেই CodeBuild Runtime Versions reference দেখুন। Correct image version নির্বাচন করুন (e.g., standard:7.0 for Node 20)।
upload_artifacts phase error Build phase-এ failure — artifact folder তৈরি হয়নি আগের phase-এর log check করুন। Build command success হয়েছে কিনা দেখুন।

AWS CodeDeploy

Symptom সম্ভাব্য কারণ সমাধান
BeforeInstall: ScriptMissing / appspec.yml not found Build artifact-এ appspec.yml নেই buildspec.yml-এর artifacts section-এ appspec.yml include করুন। base-directory সরিয়ে ফেলুন।
Deployment fails at DownloadBundle EC2 instance-এর IAM role-এ S3 permission নেই EC2 instance-এ AmazonEC2RoleforAWSCodeDeploy managed policy সহ role attach করুন।
CodeDeploy agent not running Agent install হয়নি বা service stop sudo service codedeploy-agent start এবং sudo service codedeploy-agent status দিয়ে verify করুন।
EC2 instance not found in deployment group Tag mismatch বা EC2 instance different region-এ EC2 instance-এ tag check করুন — deployment group-এর tag-এর সাথে match করতে হবে।
Blue/Green: duplicate files error Deployment folder-এ previous deployment-এর files আছে AMI তৈরির আগে sudo rm -f /var/www/my-app/* দিয়ে folder clean করুন।
ValidateService: ScriptFailed Validation script fail করেছে Script-এ error message দেখুন। /opt/codedeploy-agent/deployment-root/deployment-logs/ log check করুন।

Amazon ECS Rolling Deployments

Symptom সম্ভাব্য কারণ সমাধান
Task keeps starting and stopping (infinite loop) Docker image-এ Nginx নেই বা HTTP serve করতে পারছে না — health check fail Circuit breaker enable করুন। Dockerfile fix করে নতুন push করুন।
ECS task stuck in PROVISIONING state ASG capacity provider-এ max capacity reached বা memory insufficient ASG max capacity বাড়ান। Container instance-এর available memory চেক করুন।
imagedefinitions.json: file not found buildspec-এ generate করা হয়নি বা artifact-এ include হয়নি post_build-এ printf command ও artifacts section-এ file include আছে কিনা check করুন।
Website unreachable via ALB ALB-এ HTTP port allow security group নেই ALB-এ HTTP (80) allow করা security group attach করুন।
Blank page during rolling deployment Multiple versions serving — Angular-এ file hash mismatch Normal for rolling deployments. Deployment শেষে resolve হবে। Blue/Green ব্যবহার করুন।
ECS deploy action failed: service not found ECS service মুছে গেছে বা service name পরিবর্তন হয়েছে Pipeline-এ deploy action-এ service name update করুন।
ECR image pull failure in ECS task ECS task-এ ECR pull permission নেই বা image URI ভুল Task definition-এ execution role-এ AmazonEC2ContainerRegistryReadOnly policy দিন।

AWS CloudFormation (CodePipeline action)

Symptom সম্ভাব্য কারণ সমাধান
InsufficientCapabilitiesException Template-এ IAM resource আছে কিন্তু CAPABILITY_IAM নির্বাচন করা হয়নি CloudFormation deploy action-এ Capabilities-এ CAPABILITY_IAM add করুন।
Stack creation failed: Resource creation failed CloudFormation service role-এ permissions নেই Role-এ template-এর সব resource type-এর permissions দিন।
Template file not found in artifact Template file SourceArtifact-এ নেই বা path ভুল Git-এ cloudformation/ folder আছে কিনা check করুন। File path exactly match করতে হবে।
Parameter value missing Required parameter-এ value দেওয়া হয়নি Advanced → Parameter overrides-এ JSON format-এ সব required parameter দিন।
